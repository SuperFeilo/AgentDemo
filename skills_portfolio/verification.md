# Skill: Verification (Reflection) — Portfolio agent

## When to use
Once — after all evidence is gathered, before composing the verdict. The
agent re-derives its headline numbers from the raw tool results instead
of trusting its working memory.

## Tool
None. Verification recomputes from the blackboard's stored tool results.

## Checks
1. **Number fidelity** — recompute the stage-flow retention rates from
   the warehouse counts; recompute the signal magnitudes from the raw
   fact tables (Sum-Funnel-Stage / Sum-Claims-Stage pattern). Any
   restatement is corrected on the spot and recorded.
2. **Citation validity** — every predisposing-signal candidate must still
   clear the weight/direction screen from `lineage_analysis.md`; drop
   anything that does not match direction before composing.
3. **Stage verdict agreement** — if the assembly verdict contradicts
   the corroborating stage agent's verdict without a numeric reason,
   flag it; never silently override a stage verdict.

## Notes
- Numbers surviving re-derivation can be quoted with confidence.
- Corrections are always reported, never silent.
- This step is what makes the assembly verdict trustworthy.
