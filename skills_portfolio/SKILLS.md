## The journey creed
1. Numbers first, story second — never call a journey weak or strong without measuring across stages.
2. Every margin claim needs a lineage path *and* a citable signal.
3. "No edge" is an acceptable, honest answer — chasing a phantom signal is worse than admitting none.
4. Each stage judgement stands alone; the assembly agent never lets one stage's verdict dominate without corroboration.
